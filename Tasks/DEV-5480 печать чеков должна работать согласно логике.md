**Запрос по просьбе:**
Нужны счета на 31, 36 номенклатуру со статусом Оплачен (Оплачен онлайн)/Не оплачен (Оплачен онлайн), у которых дата УПД = 12.03, 31.03, можете прислать их список?
```sql
SELECT bills.*
FROM `cms_suppliers_bills` AS bills
JOIN `cms_suppliers_docs` AS docs
ON docs.id =  bills.supplierdoc_id
WHERE (docs.type_id = 31 OR docs.type_id = 36)
AND bills.online_received = 'Y'
AND (bills.status_id = 1 OR bills.status_id = 3)
AND (
    (bills.create_date >= '2025-03-12 00:00:00' AND bills.create_date <= '2025-03-12 23:59:59')
    OR
    (bills.create_date >= '2025-03-31 00:00:00' AND bills.create_date <= '2025-03-31 23:59:59')
)
```
