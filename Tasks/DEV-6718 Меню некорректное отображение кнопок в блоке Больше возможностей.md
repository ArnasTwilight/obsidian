## 1. Новая версия, полный продукт:
- Изначально активированы следующие инструменты:
  1. "Блок отчётов"
  2. "IP-телефония"
  3. "Интеграция с CRM"
**"IP-телефония":**
- При попытке очистить значение `"telephony_expiring_date"` инструмент активен меню
```php
unset($this->template->hotel->extra['telephony_expiring_date']);
```
- При установке даты `"2000-01-01"` инструмент активен меню
```php
$this->template->hotel->extra['telephony_expiring_date'] = "2000-01-01";
```

**"Регистрация гостей в МВД":**
- При установке даты `"3000-01-01"` инструмент активен меню
```php
$this->template->hotel->extra['scala_expiring_date'] = "3000-01-01";
```
- При очистке даты инструмент в меню деактивируется
```php
unset($this->template->hotel->extra['scala_expiring_date']);
```
- При установке даты `"2000-01-01"` инструмент активен меню
```php
$this->template->hotel->extra['scala_expiring_date'] = "2000-01-01";
```
