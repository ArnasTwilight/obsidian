Выборка
```sql
SELECT bills.*
FROM `cms_suppliers_bills` AS bills
JOIN `cms_suppliers_docs` AS docs
ON docs.id =  bills.supplierdoc_id
WHERE docs.type_id = 26
AND bills.create_date >= '2025-02-28 00:00:00'
AND bills.create_date <= '2025-02-28 23:59:59'
```
